How I work

From a messy problem to a measured result.

Every piece of work below follows the same loop. The guardrail step is the one most AI products skip.

01

Find the real problem

User research, logs and cohort data before features. At Equal: 9 personas, 1.5M+ API calls.

02

Build the smallest thing

Ship a working 0-to-1 version myself, then grow it with the people who use it.

03

Add the guardrails

Fact gates, approvals, read-only access and monitoring, so the AI is safe to trust.

04

Measure before → after

Every result is a number with a baseline: 77% → 98%, 3–4 hrs → 150 s.
